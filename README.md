## Publish
Upload **all contents of this folder** to the root of a GitHub repository.
Then enable GitHub Pages:
**Settings → Pages → Deploy from a branch → main → / (root)**.

The Home service rows link directly to the seven dedicated pages, and each service page has Previous/Next navigation.

## Contact
GitHub Pages is static, so it cannot process a server-side form by itself. The MediaBay contact form is configured to open the visitor's email client with a pre-filled message addressed to `info@mediabay.it`.
